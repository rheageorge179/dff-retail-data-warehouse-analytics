

## Project Title

**DFF Retail Data Warehouse & BI Analytics**

## Brief Description

This project designs and implements a retail data warehouse for Dominick's Finer Foods using historical store-level sales, product, traffic, coupon, and demographic data. The project converts normalized operational files into a Kimball-style dimensional model and builds data marts to answer business questions around profitability, pricing, promotions, traffic, and demographic segmentation.
